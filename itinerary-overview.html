珀斯往返西澳房车南线整体行程表

一家三口，2026 年 11 月 14 日抵达珀斯，11 月 23 日离开。11/15 起以房车南下 Busselton、Margaret River、Karri Valley、Denmark，再从 Fremantle 上 Rottnest Island 收尾。

返回完整攻略
日期 路线 夜宿区域 核心安排 驾驶 预订提醒 执行重点
D1｜11/14 周六Singapore → Perth AirportPerth / Forrestfield11:25 新加坡起飞，16:35 抵达珀斯；入境、取行李，晚餐休息。本地短途必订：机场附近住宿；不提车，房车改到 D2 处理。落地后不进 CBD，不为吃饭和取车增加变量。
D2｜11/15 周日Perth / Forrestfield → BusseltonBusselton / Broadwater取房车、熟悉操作、超市采购；随后南下 Busselton，15:00-16:00 入营。230-260 km / 3-3.5 小时必订：Mandalay Holiday Resort；确认房车交接时间、powered site 和 late arrival。核心就是移动到 Busselton 加采购，不额外塞景点。
D3｜11/16 周一Busselton → Yallingup → Margaret RiverMargaret River上午 Busselton Jetty 小火车 + 水下观景馆；午餐后经 Yallingup，Ngilgi Cave 按体力可选。90-120 km / 1.5-2 小时必订：Margaret River Tourist Park；建议订 Busselton Jetty 09:00 或 10:00 场。洞穴不是硬任务，玩不动就取消，优先保证入营节奏。
D4｜11/17 周二Margaret River → Hamelin Bay / Boranup → Margaret RiverMargaret RiverHamelin Bay 找野生鳐鱼、玩沙；午餐后 Boranup Forest，回小镇逛店或营地休息。100-130 km / 1.5-2.5 小时必订：Margaret River Tourist Park 第 2 晚；当天确认 Hamelin Bay 风浪。海滩和森林轻松日，鳐鱼只远观，不投喂不追赶。
D5｜11/18 周三Margaret River → Nannup → Karri ValleyBeedelup / Pemberton 周边经 Nannup 小镇短逛、午餐；抵达 Karri Valley 后湖边散步、迷你高尔夫或动物农场择二。150-180 km / 2.5-3 小时必订：RAC Karri Valley Resort 房车营地区；确认营地设施开放。森林营地休闲半天，不追远景点。
D6｜11/19 周四Karri Valley → Valley of the Giants → DenmarkDenmark08:30-09:00 出发，经 Walpole 休息；12:30-14:30 巨人谷树顶步道 + 地面巨树步道，随后到 Denmark 入营。190-220 km / 3-3.5 小时必订：BIG4 Denmark Ocean Beach Holiday Park；建议确认 Tree Top Walk 开放。早点出发，Tree Top Walk 是当天主体验。
D7｜11/20 周五Denmark → Greens Pool / Elephant Rocks → KojonupKojonup上午 Greens Pool / Elephant Rocks 控制 1-1.5 小时；若施工或天气不适合，改 Denmark 小镇或 Albany 备选；午餐后北上 Kojonup。220-260 km / 3-4 小时必订：Kojonup Caravan Park；Denmark 海岸按施工、风浪和天气当天决定。弹性海岸短游 + 返程中转，不为打卡拖到天黑。
D8｜11/21 周六Kojonup → Woodman Point / Fremantle 南侧Woodman Point / Fremantle 南侧09:00 出发返回 Fremantle 周边；中途午餐休息，14:00-15:00 入营；补给、洗衣、整理上岛背包。250-290 km / 3-4 小时必订：Discovery Parks - Woodman Point 第 1 晚；确认洗衣、补给和第二天接送。返程休整日，不额外塞景点。
D9｜11/22 周日Woodman Point → Fremantle Ferry → Rottnest Island → Woodman PointWoodman Point / Fremantle 南侧房车留营地，接送去 Fremantle 码头；约 09:00 上岛，Thomson Bay 找 Quokka、Pinky Beach 玩沙，约 16:00 回大陆。房车不移动；渡轮单程约 30 分钟必订：Rottnest 往返船票、码头接送、Discovery Parks - Woodman Point 第 2 晚。天气不适合出海就改大陆活动，不挪到返程当天。
D10｜11/23 周一Woodman Point → 租车门店 → Perth Airport → Singapore离开早餐、打包、清洁、排污、加油；建议 12:30-13:30 还车，14:30 左右到机场；17:50 起飞。约 40-70 km / 1-1.5 小时必确认：还车时间、清洁排污加油规则、机场到达时间。还车日只做收尾，不安排远景点或上岛。
